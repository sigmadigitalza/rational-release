# Docs map

This repo ships a static docs site in `docs/`.

- `docs/index.html` — overview and quick start
- `docs/tutorial.html` — zero-to-hero setup
- `docs/advanced.html` — advanced patterns and publishing flows
- `docs/changelog.html` — generated changelog page
- `docs/examples/` — copy-paste workflow examples

If you’re new, start with `tutorial.html`.
If you already run releases, jump to `advanced.html`.
